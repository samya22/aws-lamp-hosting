# AWS LAMP Application Hosting

## Project Overview
This project demonstrates hosting a LAMP stack web application on AWS EC2.

## Technologies Used
- AWS EC2
- Apache
- PHP
- MySQL
- Linux

## Steps Performed
1. Created EC2 instance
2. Installed Apache Web Server
3. Installed PHP
4. Configured MySQL
5. Hosted PHP application

## Outcome
Successfully deployed a LAMP stack application on AWS.
